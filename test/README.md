# Тесты

Из корня проекта в PowerShell:

```powershell
.\Scripts\python.exe -m pip install -r test/requirements.txt
.\Scripts\python.exe -m pytest -c test/pytest.ini test -q
```

Зависимости приложения должны быть установлены из корневого `requirements.txt`.
Тесты не используют рабочую БД, настройки сервера или OAuth. Данные загрузчиков
подставляются через mock; настоящие SQL-запросы этим набором не проверяются.

- `test_helper.py`: разряды, даты рейтинга, разделение контактов.
- `test_xml.py`: NULL и нулевой результат, участники, XML, карточка игрока,
  границы достижений.
- `test_tournaments.py`: выбор загрузчика для типов турнира и сборка XML пары
  с отсутствующим результатом.
- `test_db.py`: регрессия загрузки команды только с участниками вне зачёта.

Два известных дефекта помечены `xfail` с ожидаемым `KeyError`: пустой `AdminPos`
и команда только с участниками вне зачёта. Включён строгий режим: если такой
тест начнёт проходить, запуск завершится ошибкой XPASS, пока отметка не удалена.
Для просмотра причин: `python -m pytest -c test/pytest.ini test -rx`.

Следующие этапы: интеграционные тесты на отдельной MySQL с фиксированными
данными, проверки HTTP через Flask test client, отдельный прогон сериализации
по очищенной базе только на чтение. Для пустой истории рейтинга и неизвестных
ID сначала нужно согласовать ожидаемый контракт ответа.
