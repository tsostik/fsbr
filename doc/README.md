# Документация проекта FSBR DB

Дата анализа: 8 ноября 2026 года. Документация составлена по исходному коду текущего рабочего каталога.

Проект — серверное приложение Flask для базы игроков спортивного бриджа: поиск и карточки игроков, результаты турниров, рейтинги, классификация, клубные списки и регистрация новых ID. Большая часть данных публикуется в XML для использования внешним сайтом; собственный HTML-интерфейс решает отдельные задачи поиска, входа и добавления игрока.

## Границы анализа

Изучены Python-модули `src`, шаблоны, зависимости и настройки структуры проекта. Значения секретов из локального `src/settings.py` в документацию не перенесены. Базы данных и OAuth-провайдеры не опрашивались; работоспособность внешних сервисов и полнота схемы БД не подтверждены. Наличие обработчика или зависимости означает наличие реализации в репозитории, но не подтверждает успешную работу в текущем окружении.

В репозитории вместе с приложением находятся каталоги локального Python-окружения (`Lib`, `Scripts`, `Include`, `tcl`); они не являются модулями приложения. Существующая конфигурация окружения указывает на Python 3.10. Автоматизированные тесты, миграции основной БД и описание производственного развёртывания среди файлов приложения не обнаружены.
